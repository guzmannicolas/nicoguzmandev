KEY IMPLEMENTATION DETAILS
==========================

Async Loading:
- Particles load asynchronously to prevent blocking page render
- Uses (async () => { })() IIFE pattern
- loadSlim() used instead of full load for smaller bundle

Z-Index Management:
- fullScreen.zIndex: -1 renders particles behind all content
- Content should have z-index: 1 or higher
- Ensures particles don't block user interactions

Pointer Events:
- #tsparticles has pointer-events: none
- Allows clicks to pass through to content below
- Essential for non-blocking background

Hexagon Shape:
- Configured via shape.type: "polygon"
- polygon.sides: 6 creates hexagon
- Can be changed to 3 (triangle), 4 (square), 5 (pentagon), etc.

Emitters (Advanced):
- Configure in emitters array
- position.x/y: percentage-based location (0-100)
- direction: flow direction (top, bottom, left, right)
- rate.quantity: particles per spawn
- rate.delay: delay between spawns in seconds

TROUBLESHOOTING CHECKLIST
=========================

If particles not visible:
[ ] Check browser console for errors (F12)
[ ] Verify z-index: -1 in fullScreen config
[ ] Ensure #tsparticles div exists
[ ] Check that content has z-index: 1

If particles interfere with interaction:
[ ] Verify pointer-events: none on #tsparticles
[ ] Check z-index layering
[ ] Ensure interactive elements are inside <main> with z-index: 1

If performance is poor:
[ ] Reduce particleCount (try 30-50)
[ ] Set links.enable: false
[ ] Reduce moveSpeed
[ ] Disable interactivity modes not needed
[ ] Set lower fpsLimit (45 instead of 60)

CONFIGURATION REFERENCE
========================

Particle Shape Options:
- "polygon" with sides: 6 = hexagon (current)
- "polygon" with sides: 3 = triangle
- "polygon" with sides: 4 = square
- "polygon" with sides: 5 = pentagon
- "circle", "square", "star" also available

Interactivity Modes:
- repulse: Push particles away on hover
- push: Add new particles on click
- grab: Attract particles to mouse
- bubble: Magnify particles near mouse
- remove: Remove particles on click

Color Examples:
- Professional: "#a0a0ff" (purple-blue)
- Modern: "#00ffff" (cyan)
- Tech: "#00ff88" (green)
- Classic: "#ffffff" (white)
