LIBRARY INSTALLED
  Package: tsparticles@2.12.0
  Manager: pnpm
  Size: ~100KB gzipped

SIMPLEST USAGE (Copy & Paste Ready)
=============================================================

1. In any .astro file, add:
   ---
   import ParticlesBackground from "../components/ParticlesBackground.astro";
   ---
   
   <ParticlesBackground />
   <main>Your content here</main>

That's it! Particles render behind your content.

CUSTOMIZABLE VERSION
=============================================================

<ParticlesCustom 
  config={{
    particleCount: 100,        // 30-200 recommended
    particleColor: "#00ff88",  // Any hex color
    particleSize: 4,           // 1-10
    linkDistance: 200,         // 50-300
    moveSpeed: 2.5,            // 0.5-5
  }}
/>

READY-MADE LAYOUT
=============================================================

---
import LayoutWithParticles from "../layouts/LayoutWithParticles.astro";
---

<LayoutWithParticles title="Page Title">
  <h1>Your content</h1>
</LayoutWithParticles>

SHAPE OPTIONS (Hexagon is default)
=============================================================

Hexagon (6 sides):    shape: { type: "polygon", polygon: { sides: 6 } }
Triangle (3):         shape: { type: "polygon", polygon: { sides: 3 } }
Square (4):           shape: { type: "polygon", polygon: { sides: 4 } }
Pentagon (5):         shape: { type: "polygon", polygon: { sides: 5 } }
Circle:               shape: { type: "circle" }

PERFORMANCE ADJUSTMENTS
=============================================================

Slow device?
  - Reduce particleCount to 30-50
  - Set links.enable: false
  - Reduce moveSpeed to 1
  - Set fpsLimit: 45

Fast device?
  - Increase particleCount to 150+
  - Keep links enabled
  - Increase moveSpeed to 3-5

TROUBLESHOOTING
=============================================================

Particles not visible?
  → Check z-index: -1 in config
  → Check background color visibility
  → Check browser console for errors

Content not clickable?
  → Verify pointer-events: none on #tsparticles
  → Check content z-index: 1 or higher

Particles laggy?
  → Reduce particleCount
  → Disable links
  → Close other tabs/apps
  → Check browser devtools performance

KEY CONCEPTS
=============================================================

Z-Index Layering:
  Content:    z-index: 1  (appears on top)
  Particles:  z-index: -1 (appears behind)

Pointer Events:
  #tsparticles { pointer-events: none }
  Allows clicks to pass through to content

Async Loading:
  (async () => { await loadSlim(...) })()
  Doesn't block page render

Hexagon Shape:
  shape: { type: "polygon", polygon: { sides: 6 } }
  Can change sides to 3, 4, 5, etc.

MOST COMMON EDITS
=============================================================

Change color:
  Find: particleColor: "#ffffff"
  Change to: particleColor: "#00ff88"

Change particle count:
  Find: number: { value: 80 }
  Change to: number: { value: 150 }

Change interaction behavior:
  Find: mode: "repulse"
  Options: "repulse", "push", "grab", "bubble"

Disable particle links:
  Find: links: { enable: true }
  Change to: links: { enable: false }
