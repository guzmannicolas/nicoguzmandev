# Nicolás Guzmán — Software Engineering & AI Studio

> High-impact digital solutions for commercial businesses and growing enterprises: high-speed web presence, 24/7 AI WhatsApp automation, and custom ERP management systems.

🌐 Live Production Website: **[nicoguzmandev.com](https://nicoguzmandev.com)**

---

## 🎯 Commercial Offerings

1. **🌐 Branch 1: Web Presence for Local Businesses (`/webs`)**
   - High-speed static websites built with Astro 5.
   - 100% mobile responsive with WhatsApp direct ordering and Google Maps local SEO.
   - Integrated with our live 8-template showroom at [templates.nicoguzmandev.com](https://templates.nicoguzmandev.com).

2. **🤖 Branch 2: Automation & AI Agents (`/automatizacion`)**
   - Intelligent 24/7 WhatsApp bots powered by LLMs (not rigid numeric menus).
   - Real-time appointment scheduling synchronized directly with Google Calendar.
   - Instant lead capture and automated reminders to eliminate no-shows.

3. **🏢 Branch 3: Custom Software & ERP Systems (`/erp`)**
   - Centralized multi-branch inventory control and order tracking.
   - Role-based access control and executive KPI dashboards.
   - Custom-tailored without expensive per-seat recurring fees.

## 🛠️ Tech Stack

- **Framework:** [Astro 5](https://astro.build/)
- **Styling:** [Tailwind CSS 4](https://tailwindcss.com/) with `@tailwindcss/vite`
- **UI Components:** React 19, Lucide Icons, Framer Motion
- **Hosting & Infrastructure:** [Vercel](https://vercel.com/) + [Cloudflare](https://cloudflare.com/)

## 🚀 Development

```bash
# Install dependencies
pnpm install

# Start local development server
pnpm run dev
# -> http://localhost:4321

# Build for production
pnpm run build
```
